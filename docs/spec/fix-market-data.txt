FIX Market Data
  FIX Market Data Gateway API Reference
  FIX 5.0 SP2

  The channel expressed trade, orderbook, open interest & trading volume, instrument_lifecycle in
  FIX 5.0 SP2 message types.

     -​    Session layer: FIXT.1.1
     -​    Application layer: FIX 5.0 SP2 (DefaultApplVerID = 9)
     -​    Baseline: FIX 5.0 SP2, with CPM-specific extensions in the 20000+ / U-prefixed / F1–F5
           ranges.




  1. Connection & Session
Property                                           Value

Protocol                                           FIX 5.0 SP2 (FIXT.1.1)

Transport                                          TCP

Default Port                                       TBD

TargetCompID (56)                                  CPMMD

BeginString (8)                                    FIXT.1.1

DefaultApplVerID (1137)                            9 (FIX50SP2)

SendingTime precision                              Microseconds inbound / milliseconds outbound

Heartbeat interval                                 30 seconds (configurable on Logon)


  Each FIX session maps to a registered trading user identified by SenderCompID, which must
  match the user's API Key. The API Key must carry the MARKET_DATA permission.

  Sequence Numbers. Send ResetSeqNumFlag=Y on Logon to reset sequence numbers.
  Sequence numbers may not be persisted across restarts.

                        3. Authentication (Logon 35=A)
                        Send a FIX Logon to establish a session. The gateway validates credentials and responds with
                        a Logon ack or Logout. Authentication uses an API key carried in SenderCompID(49) +
                        passphrase (Password 554) + an HMAC signature (Text 58). The gateway checks for
                        MARKET_DATA permission.


Tag              Name                                 Type                               Req                                Description

98               EncryptMethod                        Int                                Y                                  0 = No encryption

108              HeartBtInt                           Int                                Y                                  Heartbeat interval in seconds.
                                                                                                                            Recommended: 30

141              ResetSeqNumFlag                      Boolean                            N                                  Y to reset sequence numbers on
                                                                                                                            connect

1137             DefaultApplVerID                     String                             Y                                  9 (FIX50SP2)

554              Password                             String                             Y                                  Passphrase. Must be non-empty.

58               Text                                 String                             N                                  HMAC signature bytes. Must be
                                                                                                                            non-empty.


                        The API key is carried in the standard header field SenderCompID(49), not in a Logon-body
                        field.

                             4.1 MDEntryType (269) → channel mapping
       MDEntryType                          Channel                             WebSocket equivalent                Response messages

       0 Bid                                Order book — YES bids               orderbook                           W snapshot then X deltas

       1 Ask                                Order book — NO bids                orderbook                           W snapshot then X deltas

       2 Trade                              Public trades                       trade                               X incremental only

       B Trade volume                       Trade volume                        None, included in ticker channel    W snapshot then X deltas

       C Open interest                      Open interest                       None, included in ticker channel    W snapshot then X deltas

       L (custom) InstrumentLifecycle       Instrument lifecycle                instrument_lifecycle                f SecurityStatus


                             Subscription scoping :

                                  -​   L1 & L2 Order book: subscribe by instrument only
                                  -​   Trade, Trade volume, Open Interest, Instrument lifecycle: subscribe by instrument(s)
                                       or all-instruments subscription..


                             4.2 Snapshot behavior
                                  -​   Order book, Trade volume, Open Interest: an initial W MarketDataSnapshotFullRefresh
                                       is sent on subscribe, followed by X MarketDataIncrementalRefresh updates.
                                  -​   Trade, Instrument lifecycle: no snapshot is sent; only live updates are delivered after
                                       subscribe.

          5. Order Book (L1 and L2) & Trades
          The channel that emits messages for L1, L2 orderbook and trade information. Message type
          can be distinguished by tag 264 market depth and tag 269 market data entry type and tag 1023
          price level.

                1.​ Real-time order book — L1, L2 market data, depth of market. WebSocket equivalent: the
                    orderbook channel. Delivered as W orderbook_snapshot on subscribe (up to 10
                   levels per side), then X orderbook_delta updates.
                2.​ Trade feed for volume analysis. WebSocket equivalent: the trade channel. Delivered as
                   X MarketDataIncrementalRefresh only (no snapshot), immediately after trade execution.

          The ticker is carried in the standard MD entries. CPM maps ticker fields to MD entry types as
          follows:


      MDEntryType (269)                   Meaning                            Fields

      2 Trade                             Last trade                         MDEntryPx(270) = last_price,
                                                                             MDEntrySize(271) =
                                                                             last_trade_size

      0 Bid                               Best YES bid                       MDEntryPx(270) = yes_bid,
                                                                             MDEntrySize(271) =
                                                                             yes_bid_size

      1 Ask                               Best NO bid                        MDEntryPx(270) = no_bid,
                                                                             MDEntrySize(271) = no_bid_size

      B Trade volume                      Total contracts traded             MDEntrySize(271) = total
                                                                             contracts traded

      C Open interest                     Open interest, number of open      MDEntrySize(271) = number of
                                          contracts                          open contracts

6. Instrument Lifecycle
Tracks lifecycle changes: creation, (de)activation, close-date changes, determination,
settlement. This is the FIX counterpart of the WebSocket instrument_lifecycle channel,
but slimmed to the trading-status fields below: the WebSocket channel emits the complete
Instrument resource (every field, including additional_metadata), whereas the FIX
SecurityStatus(f) carries only Symbol(55) + SecurityID(48) +
SecurityTradingStatus(326) + TransactTime(60). Per-instrument and all-instruments
subscriptions supported.

Instrument symbol and statuses are delivered as SecurityStatus (35=f).
